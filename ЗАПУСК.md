# Как запустить бота на своём компьютере (Windows)

## Один раз

1. **Установите Docker Desktop**: https://www.docker.com/products/docker-desktop/
   После установки перезагрузите компьютер и откройте Docker Desktop. Внизу слева должен появиться зелёный статус «Engine running».

2. **Создайте бота** в Telegram: напишите [@BotFather](https://t.me/BotFather) команду `/newbot` и следуйте подсказкам. В конце он пришлёт **токен** вида `1234567890:AAH...`.

3. **Узнайте свой ID**: напишите [@userinfobot](https://t.me/userinfobot). Он ответит числом, это ваш **Id**.

4. Откройте файл `src\.env` в Блокноте. Пароли для базы данных в нём уже сгенерированы. Заполните две строки:
   ```
   TELEGRAM=токен_от_BotFather
   OWNER_ID=ваш_Id
   ```
   Там же укажите свой часовой пояс, чтобы даты показывались правильно, например:
   ```
   TIMEZONE=Asia/Tashkent
   ```
   (Москва: `Europe/Moscow`, Минск: `Europe/Minsk`, Алматы: `Asia/Almaty`.)
   Сохраните файл. Никому его не отправляйте.

## Бот для всех

В `src\.env` стоит `ACCESS_MODE=public`, то есть ботом может пользоваться любой человек. Отправьте друзьям ссылку на бота (`t.me/имя_бота`). При первом запуске каждый выбирает язык (русский, узбекский, английский, белорусский) и валюту и сразу получает готовые категории. Данные у всех раздельные: никто не видит чужие записи. Резервные копии и `/backup` приходят только вам.

Чтобы снова сделать бота только для себя, поставьте `ACCESS_MODE=owner`.

Суммы можно писать коротко: `500к`, `200 тыс`, `1.5 млн`, `300 ming`. В «📊 Баланс» видно, сколько это в долларах и евро, а в «⚙️ Настройки» → «💹 Курсы» — курсы на сегодня.

## Сообщения от пользователей и ошибки

- Любой пользователь может нажать «⚙️ Настройки» → «✉️ Написать разработчику» (или `/feedback`) и прислать текст или скриншот. Сообщение придёт вам в Telegram с кнопкой «↩️ Ответить»: нажмите её и напишите ответ, бот перешлёт его человеку.
- Если у кого-то в боте случится ошибка, вам придёт уведомление «🐞 Ошибка» с местом в коде (без сумм и текстов пользователя). Одинаковые ошибки приходят не чаще раза в 10 минут. Подробности смотрите командой `docker compose logs --tail 100 app`.

## Raspberry Pi (Linux)

Нужна **64-битная** система (Raspberry Pi OS 64-bit или Ubuntu): проверьте командой `uname -m`, ответ должен быть `aarch64`.

1. Установите Docker и git (один раз):
   ```
   sudo apt update && sudo apt install -y git
   curl -fsSL https://get.docker.com | sh
   sudo usermod -aG docker $USER
   ```
   Затем выйдите из системы и войдите снова (или `sudo reboot`).
2. Скачайте бота и запустите:
   ```
   git clone https://github.com/SA1D77/Finance-telegram-bot.git
   cd Finance-telegram-bot
   ./start.sh
   ```
   При первом запуске `start.sh` создаст `src/.env` с паролями. Откройте его (`nano src/.env`), впишите `TELEGRAM=`, `OWNER_ID=`, `ACCESS_MODE=public`, `TIMEZONE=Asia/Tashkent`, сохраните (Ctrl+O, Enter, Ctrl+X) и снова выполните `./start.sh`. Первая сборка на Raspberry Pi занимает 10–20 минут.
3. Бот сам запускается после перезагрузки. Остановить: `./stop.sh`, логи: `docker compose logs -f app`, обновить: `git pull && ./start.sh`.

**Перенос данных с компьютера:** напишите боту `/backup`, скачайте присланный файл, положите его в папку `backups` на Raspberry Pi и выполните `./restore.sh backups/finance-….sql.gz`.

**Важно:** запускайте бота только в одном месте. Перед запуском на Raspberry Pi остановите его на компьютере (`stop.bat`), иначе Telegram не даст работать двум копиям с одним токеном.

## Каждый раз

- **Запустить:** двойной щелчок по `start.bat` (Docker Desktop должен быть открыт). Первый запуск займёт несколько минут.
- **Остановить:** `stop.bat`. Записи сохраняются.
- Бот отвечает только вам. Остальным он не отвечает вообще.

## Быстрый ввод

Можно не нажимать кнопки, а просто написать боту:
- `500 кафе обед` — расход 500 в категорию «кафе» с комментарием «обед»;
- `+50000 зарплата` — доход;
- `1200+350*2 продукты` — бот посчитает (1900) и спросит, сохранить ли.

Если категории нет или вы опечатались, бот предложит варианты кнопками.

## История и исправления

- Кнопка **📜 История** (или команда `/history`) показывает операции по 5 на странице, с фильтрами по периоду и категории.
- Нажмите номер операции, чтобы изменить сумму, категорию, комментарий или дату или удалить её (бот спросит подтверждение).
- Под каждой новой записью есть кнопка **↩️ Отменить**. Команда `/undo` предлагает удалить последнюю операцию.

## Бюджет

- Кнопка **🎯 Бюджет** (или `/budget`) показывает, сколько потрачено за месяц, сколько осталось и сколько можно тратить в день.
- **🎯 Общий лимит** задаёт лимит на все расходы за месяц, **➕ Лимит на категорию** — на одну категорию. Чтобы убрать лимит, введите `0`.
- Когда расходы дойдут до 80% и до 100% лимита, бот пришлёт предупреждение. Каждое приходит один раз за месяц.

## Аналитика и отчёты

- Кнопка **📈 Аналитика** (или `/stats`) показывает итоги месяца:
  - доходы, расходы и какую долю дохода удалось сохранить;
  - средний расход в день, прогноз на конец месяца и сколько можно тратить в день;
  - сравнение с прошлым месяцем по категориям, топ категорий и самые крупные траты.
  Кнопки ◀️ ▶️ листают месяцы, а «📊 Динамика за 12 месяцев» присылает график.
- `/report` делает отчёт (Excel и диаграммы) за сегодня, неделю, месяц, год или свой период, например `01.09.2026-30.09.2026`.

## Регулярные операции

Кнопка **🔁 Регулярные** (или `/recurring`) → **➕ Добавить** → напишите, например, `5000 интернет` или `+90000 зарплата`, выберите частоту, дату и напоминание. Бот сам добавит операцию в нужный день и пришлёт сообщение с кнопкой «↩️ Отменить». Если включено напоминание, бот предупредит заранее: следующий раз можно пропустить или поменять сумму.

## Цели накопления

Кнопка **⭐ Цели** (или `/goals`) → **➕ Новая цель**: название, сумма, срок (или «-»). Бот покажет прогресс и сколько откладывать в месяц, чтобы успеть. Кнопки «💰 Пополнить» и «➖ Снять» отмечают отложенные деньги. На баланс это не влияет.

## Несколько валют

Впишите в `src\.env` свою основную валюту, например `BASE_CURRENCY=UZS`. После этого можно писать `50 usd кафе`, `50$ отель`, `20 евро такси`: бот пересчитает сумму по курсу дня и спросит подтверждение. Все итоги считаются в основной валюте, а исходная сумма видна в истории и в экспорте.

## Голос и фото чека

В `src\.env` поставьте `FEATURE_VOICE=1` и/или `FEATURE_RECEIPTS=1` и запустите `start.bat`. Первый запуск будет дольше: скачиваются распознаватели, около 150–300 МБ.
- **Голос:** отправьте голосовое «пятьсот кафе обед» или «плюс пятьдесят тысяч зарплата». Бот покажет, что услышал, и попросит подтвердить.
- **Чек:** отправьте фото чека (можно с подписью-категорией, например «продукты»). Бот найдёт итоговую сумму и спросит категорию.
- Всё распознаётся на вашем компьютере, бесплатно, без отправки в интернет.

## Если что-то не работает

Откройте папку проекта, в адресной строке Проводника наберите `cmd` и нажмите Enter. Затем выполните:
```
docker compose logs --tail 50 app
```
Пришлите вывод разработчику. Токенов и паролей в логах нет.

## Экспорт и резервные копии

- `/export` присылает операции за период файлом **CSV** или **Excel**.
- Каждую ночь (в 3:00, настройка `BACKUP_HOUR`) бот сам делает резервную копию базы. Она ложится в папку `backups` (хранятся 7 последних), а файл приходит вам в Telegram. Команда `/backup` делает копию прямо сейчас.
- **Восстановление:** перетащите файл копии мышкой на `restore.bat` (или выполните `restore.bat backups\finance-….sql.gz`). Бот спросит подтверждение, заменит данные и запустится снова.
- Без копии удаление Docker Desktop или команда `docker compose down -v` **стирают все записи**.
